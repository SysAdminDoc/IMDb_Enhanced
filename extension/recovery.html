Granted host access:

    Site access

    Features that reach a site other than IMDb ask for access to that site only, and only when you switch them on. This page is the only place a browser will let an extension request it, so grant and revoke happen here.

    Backup

    A normal backup leaves out integration API keys and tokens and tells you which it left out.

    The backup is encrypted in this browser with the passphrase you choose. There is no way to recover the contents if you forget it.

    Restore

    Reset

    Returns every preference, site list, title mark, and integration credential to its default. You can undo it once, without leaving this page.

    This clears title marks and local integration credentials. Copy a backup first if you may need them.

    Available until you leave this page.
